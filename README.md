**Project Overview**

This repository contains my Digital Literacy Portfolio, created as part of my role as a Student Digital Ambassador. The project focuses on helping students understand how to use digital tools responsibly, communicate professionally, and stay safe online.

The portfolio is divided into five modules covering:

Digital awareness
Professional online presence
Coding & collaboration tools
Email etiquette
Cybercrime awarenes
